# Contributing

Thanks for wanting to help.

The icons in this repository are drawn in Antheo's own icon studio and generated into the packages, so the icon files
here are not edited by hand and pull requests that change them can't be merged.

What helps most:

- **Ask for an icon.** Open an issue with the icon's name and what it is for. Requests that many people ask for get
  drawn first, into both families.
- **Report a bug.** Open an issue with the package, its version, your framework and a short example that shows it.
- **Improve the docs.** Pull requests that fix or clarify the READMEs and the guide are welcome.

To work on the docs or the components locally:

```bash
npm install
npm run build
npm test
```
