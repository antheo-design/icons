# Changelog

Both packages share one version number and are released together.

## 1.1.1

- Clearer drawings for grip (a drag handle with arrows), loader (a spinner ring), fingerprint and tablet (held
  sideways, with a stylus), in both families.

## 1.1.0

- 69 new icons in both families, 350 in each now: sidebar, columns, table, grip, move, minimize, more-vertical,
  toggle, loader, circle-x, circle-plus, circle-check, trending-down, frown, ban, activity, server, git-branch, hash,
  percent, bug, cloud-upload, cloud-download, line-chart, shield, shield-check, fingerprint, qr-code, scan, save,
  file-plus, folder-plus, bookmark-plus, dashboard, wifi-off, banknote, bank, package, barcode, discount, user-check,
  user-x, user-circle, user-minus, timer, history, navigation, route, signpost, tablet, watch, tv, speaker,
  camera-off, heart-pulse, pill, hand, wrench, hammer, cloud-sun, storm, wind, thermometer, bell-off,
  battery-charging, headset, badge-check, life-buoy and ruler.
- Lucide-style names: `X`, `AlertTriangle`, `Bot`, `ShoppingCart`, `Zap` and nearly 90 more are exported as other
  names for our icons. Each icon's other names are in `icons.json` under `aliases`.
- Tufted: moving parts that are perfectly straight lines no longer disappear in the felt.

## 1.0.0

First release.

- `@antheo/painted-icons`: 281 painted icons as React components, with still and animated SVG files
- `@antheo/tufted-icons`: the same 281 icons in felt, with still and animated SVG files
- Hover moves, a parent trigger class, colour props, `iconNames`, `categories` and `icons.json`
