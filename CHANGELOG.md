# Changelog

Both packages share one version number and are released together.

## 1.0.0

First release.

- `@antheo/painted-icons`: 281 painted icons as React components, with still and animated SVG files
- `@antheo/tufted-icons`: the same 281 icons in felt, with still and animated SVG files
- Hover moves, a parent trigger class, colour props, `iconNames`, `categories` and `icons.json`
